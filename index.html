How Local Network Discovery Works

Because cloud servers are hosted in secure remote data centers, they cannot penetrate through your home Wi-Fi router's NAT firewall to directly scan your private local area network (LAN). To map your exact devices, you can run the included standalone Python scanner script on your own computer, which outputs a network_map.json file that you can load here in 1 click!

1 Run Discovery on Your Local Machine

Open Terminal (macOS/Linux) or PowerShell/Command Prompt (Windows) on any computer connected to your home Wi-Fi:

# Python Standard Library Scanner (Included in this repo)
python3 network_mapper.py
Alternative Industry Tools:
Nmap Ping Sweep: nmap -sn 192.168.1.0/24
ARP-Scan (Linux/Mac): sudo arp-scan --localnet
Windows PowerShell ARP: Get-NetNeighbor -AddressFamily IPv4
